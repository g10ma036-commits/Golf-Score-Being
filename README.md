# ⛳ Golf Enjoy Manager

ゴルフのスコア記録・統計分析・ラウンド分析・アルバム・クラブセッティング・飛距離記録を、
自分のPCだけで管理できるローカルアプリです。データは外部に送信されません。

## 起動方法

必要なもの：**Node.js 22.13 以上**（追加のパッケージのインストールは不要です）

- **Windows**：`start.bat` をダブルクリック → ブラウザが自動で開きます
- **コマンドから**：`npm start` を実行して <http://localhost:3000> を開く

終了するときは、黒いウィンドウで `Ctrl + C` を押すか、ウィンドウを閉じます。

初めて使うときは、ホーム画面または「設定」→「サンプルデータを読み込む」で、
架空のデータを入れて各機能を試せます（データが空のときだけ使えます）。
試し終わったら、ホーム画面の「**サンプルデータを削除**」（または「設定」→「サンプルデータを削除」）で、
サンプルだけを消せます。自分で登録したデータは残ります（サンプルのコースで記録したラウンドは一緒に消えます）。

| 画面 | 内容 |
| --- | --- |

| 統計分析 | 期間・コースで絞り込み。ミスの影響（FWを外した・3パット・OB・バンカーのとき何打多いか、1ラウンドでの損失の目安）、平均スコア、パット、FWキープ率、パーオン率（パーオン時のパット）、ボギーオン率、1パット率、リカバリー率、3パット率、パー別平均、ティーショットの方向、月別推移など |
| AIに分析してもらう | 総合分析・練習メニュー・目標達成プラン・ラウンドの振り返り・コース攻略・クラブ相談・自由に質問から目的を選ぶと、記録をまとめた質問文（プロンプト）を作成。コピーして ChatGPT・Claude・Gemini などに貼り付けるだけ（アプリから自動送信はしない・名前と同伴者は含めない・料金不要）。答えの長さの指定、続けて聞くと良い質問の例つき |
| 年間のまとめ | 1年のラウンド数・ベスト・平均（前の年との比較）・月別のラウンド数と平均・記録（最少パット・最多バーディなど）・初めての100切りなどの節目・回ったコース。1枚の画像にして共有もできる |
| 実績 | 初めての100切り・ハーフ40切り・初バーディ・パー以内の連続・30パット以下・ラウンド数など 25 項目。達成した日とラウンドを表示 |
| コース | パー・ヤード・HDCP・コースレート/スロープを登録（コースガイドの表を貼り付けて自動入力も可）。27・36ホールのゴルフ場は東・西・南コースなど9ホールずつ登録し、スコア入力で前半・後半に回ったコースを選べる。攻略シート（ホールごとの目標打数・パー3の番手の目安・過去の平均と前回・メモ。印刷も可）、登録したコースをファイル／テキストで友達に渡す・もらったコースを読み込む（スコアやメモは含まない）。ホール別の得意・苦手分析 |

| 使い方 | スコア記録・コース登録・分析・AI分析・バックアップの説明と、よくある質問 |

### 計算方法のメモ

- **パーオン**：`スコア − パット ≦ パー − 2` で自動判定（パットを入力したホールのみ）
- **リカバリー率**：パーオンしなかったホールでパー以上だった割合
- **推定ハンディキャップ**：直近20ラウンド（18H）のうち良い8つのディファレンシャル平均（1ホールの上限はトリプルボギー）。コースレート/スロープ未登録の場合はパーと113で計算する簡易版です

## データの保存場所とバックアップ

すべてのデータはこのフォルダ内の `data/` に保存されます。

```text
data/
  golf.db        … スコア・コース・クラブ・飛距離などのデータベース（SQLite）
  photos/        … アップロードした写真（元画像）
  photos/thumbs/ … 一覧表示用のサムネイル
```

**`data` フォルダごとコピーすれば、写真も含めた完全なバックアップ**になります。
「設定」の「写真込みでバックアップ（ZIP）」でも写真を含めて保存できます（「データのみ（JSON）」は写真ファイル本体を含みません）。

保存先を変えたい場合は環境変数 `GOLF_DATA_DIR` を指定してください。

## 📱 スマホ（iPhone / Android）で見る

PC でアプリを起動したまま、**同じ Wi-Fi につながったスマホ**から見たり入力したりできます。

1. PC のアプリで、左下の「**スマホで見る**」（または「設定」→「スマホで見る」）を開き、「スマホからのアクセスを許可する」を押す
2. 初回だけ PC に「Windows セキュリティの重要な警告」が出るので、**「プライベート ネットワーク」にチェックして「アクセスを許可する」**
3. 表示された **QR コードをスマホのカメラで読み取る**（iPhone・Android 共通）
4. 開いたページを**ホーム画面に追加**するとアプリのように使えます
   - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
   - Android（Chrome）：︙ →「ホーム画面に追加」／「アプリをインストール」

QR が読めないときは、スマホのブラウザで表示されたアドレス（例：`http://192.168.1.10:3000`）を開き、6桁の**接続コード**を入力します。

### 安全のしくみ

- QR コードか接続コードで登録したスマホだけが見られます（同じ Wi-Fi の他の端末は見られません）
- 接続コードを5回間違えると一時的にロックされます
- 「接続をリセット」で QR・接続コードを作り直すと、登録済みのスマホはすべて解除されます
- 許可の ON/OFF・リセットは PC からのみ操作できます

### スマホ向けの画面

- 画面下のタブメニュー（中央の「＋」ですぐスコア入力）
- 「1ホールずつ」入力：大きなボタンをタップしてスコア・パット・FW・OB を入力
- グラフはタップで数値を表示（同じ点をもう一度タップでラウンド詳細へ）
- 写真はスワイプで切り替え、スマホのカメラ・写真ライブラリから直接追加

**つながらないとき**：スマホと PC が同じ Wi-Fi か／Windows の Wi-Fi が「プライベート ネットワーク」になっているか／ゲスト用 Wi-Fi でないか（端末どうしの通信が禁止されている場合があります）を確認してください。PC がスリープすると見られなくなります。

※ 外出先（ゴルフ場など）からは見られません。外で使うには、次の「スマホ単独版」を使います。

## 📲 スマホ単独版（PC なしで使う）

PC を起動していなくても、スマホだけで記録・分析・アルバムが使える版です。

- データは**スマホの中**（ブラウザの保存領域）に保存されます。外部のサーバーには送信されません
- 一度開けば**電波のないゴルフ場でも**使えます（オフライン対応）
- 画面と機能は PC版と同じです（写真は容量節約のため長辺 2048px に縮小して保存）
- PC版とは**別のデータ**です。行き来するときは、下の「写真込みバックアップ（ZIP）」を使います

### 作り方と公開

1. `npm run build:phone` を実行 → `dist/phone-app` フォルダができます
2. このフォルダの中身を、**https** で配信できる静的ホスティングに置きます（GitHub Pages / Netlify / Cloudflare Pages など。無料で使えます）
3. 公開した URL を `public/js/config.js` の `PHONE_APP_URL` に書くと、PC版の「設定」にスマホで開くための QR コードが出ます

PC で試すだけなら `npm run preview:phone` → <http://localhost:4173>。

#### GitHub Pages で公開する場合

`.github/workflows/pages.yml` が入っているので、GitHub に push するだけで自動的にテスト → ビルド → 公開されます。

1. GitHub で新しいリポジトリを作る（Public。README などの追加はしない）
2. このフォルダで `git init -b main` → `git add .` → `git commit` → `git remote add origin https://github.com/ユーザー名/リポジトリ名.git` → `git push -u origin main`
3. リポジトリの **Settings → Pages → Source** を「**GitHub Actions**」にする
4. **Actions** タブで「スマホ単独版を公開」が緑のチェックになれば完了（最初の実行が失敗していたら「Re-run all jobs」）
5. `https://ユーザー名.github.io/リポジトリ名/` をスマホで開いて、ホーム画面に追加

以降は push するたびに自動で更新され、スマホのアプリに「更新する」が表示されます。
公開されるのはプログラムだけで、記録データ（`data/`）は `.gitignore` で除外されています。

※ オフライン機能とホーム画面への追加には https が必要です。PC の LAN アドレス（http）で配信したものは単独では動きません。

### スマホでの使い始め

1. 公開した URL をスマホで開く（iPhone は **Safari**、Android は **Chrome**）
2. **ホーム画面に追加**する
   - iPhone：共有ボタン →「ホーム画面に追加」
   - Android：︙ →「ホーム画面に追加」／「アプリをインストール」
3. ホーム画面の **Golf** アイコンから開いて使う

**iPhone の注意**：Safari で入力したデータは、ホーム画面に追加したアプリには引き継がれません。**先にホーム画面に追加してから**記録してください。

### バックアップとデータの引っ越し

スマホ単独版のデータはその端末の中だけにあります。**アプリ（ホーム画面のアイコン）を削除したり機種変更したりすると消える**ので、ときどきバックアップしてください。

- **スマホ**：「設定 → バックアップを作成（写真込み）」→「共有・保存する」で、「ファイルに保存」・Google ドライブ・LINE（自分へのトーク）などに保存
- **PC版**：「設定 → 写真込みでバックアップ（ZIP）」
- どちらの ZIP も、もう一方の「設定 → バックアップから復元」で読み込めます（PC → スマホ、スマホ → PC のどちらも可）
- 復元すると、復元先のデータは**すべて置き換わります**（合算はされません）。メインで記録する端末をどちらかに決めて使うのがおすすめです

ホーム画面には、14日以上バックアップしていないとお知らせが出ます。

### 友達にも使ってもらう

- 公開した URL を送るだけで使えます。データは一人ずつそれぞれのスマホに保存され、ほかの人からは見えません
- 初めて開くと、ホーム画面に「はじめに」の案内（ホーム画面に追加 → コース登録 → スコア記録 → バックアップ）が出ます
- 同じゴルフ場によく行くなら、「コース」→「友達に渡す」でコース情報（パー・ヤード・HDCP など）を送り、相手は「読み込む」で登録できます

## 開発者向け

```text
server.js          起動・待ち受け（スマホ許可の ON/OFF で待ち受けアドレスを切り替え）
server/app.js      リクエスト処理（静的ファイル・写真配信・スマホ接続の認証）
server/lan.js      スマホ接続（秘密キー・接続コード・ロック・LAN アドレス）
server/db.js       SQLite スキーマ（node:sqlite）
server/api.js      REST API（SQLite）
server/sample.js   サンプルデータを SQLite に書き込む
public/            画面（素の JavaScript の SPA。グラフは自作 SVG）
  css/mobile.css   スマホ向けスタイル
  js/shared/       PC版とスマホ単独版で共用：入力チェック（model.js）・サンプル生成・ZIP・バックアップ形式・コース共有ファイル（courseFile.js）
  js/local/        スマホ単独版のブラウザ内 API（backend.js は server/api.js と同じ結果を返す）と IndexedDB 保存
  js/standalone.js スマホ単独版のオフライン対応・更新のお知らせ・ホーム画面追加・バックアップ共有
  js/qr.js         QR コード生成（外部ライブラリなし）
  js/stats.js      スコア統計の計算（目標の配分・年間のまとめ・達成・番手の目安なども）
  js/aiPrompt.js   AI に貼り付ける質問文（プロンプト）の作成（送信はしない）
  js/draft.js      スコア入力の下書き（端末に自動保存）
  js/share.js      ファイルの共有・ダウンロード
  js/csv.js        スコアの CSV 書き出し
  js/charts.js     グラフ部品（折れ線・棒・横棒・レンジ・構成比バー）
  js/views/        各画面
scripts/           スマホ単独版のビルド（build-phone.js）・Service Worker のひな形・プレビュー用サーバー
test/              自動テスト（npm test）
```

- 外部パッケージなし。`npm test` で API・統計計算・スマホ接続のテストに加え、**スマホ単独版の API が PC版サーバーと同じ結果を返すか**（同じ操作を両方に送って比較）、バックアップ ZIP の互換性、ビルド結果を確認できます
- ポート変更：`set PORT=3001 && npm start`
- `GOLF_ALLOW_LAN=1`：スマホからのアクセスを常に許可（画面からの OFF 不可）
- `GOLF_LAN_HOST`：スマホ許可時の待ち受けアドレス（既定 `0.0.0.0`）
